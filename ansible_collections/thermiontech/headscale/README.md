# Ansible Collection - thermiontech.headscale <!-- omit in toc -->
This collection provides a series of Modules to interact with the Headscale API.

## Modules
- [`thermiontech.headscale.get_pre_auth_key`](): Ansible module to retrieve a preAuthKey from a Headscale instance.
- [`thermiontech.headscale.get_node_id_from_name`](): Ansible module to retrieve a Headscale node id based on the node name.
- [`thermiontech.headscale.remove_node`](): Ansible module used to remove a specific node from Headscale.
